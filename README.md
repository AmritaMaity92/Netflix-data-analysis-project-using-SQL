# Netflix-data-analysis-project-using-SQL
Netflix Data Analysis Using SQL
**Project Overview**

This project analyzes Netflix's movie and TV show dataset using SQL queries. The objective is to extract meaningful insights, identify trends, and answer business-related questions from the data.
**Dataset**
The dataset contains information about Netflix content, including:
Show ID
Title
Type (Movie/TV Show)
Director
Country
Date Added
Release Year
Rating
Duration
Genre (Listed In)

**Key Analysis Performed**
1. Count Total Movies and TV Shows
2. Top Countries Producing Netflix Content
3. List of all movies and TV shows released in particular year.
4. Titles of all movies directed by particular director.
5. Find Most Common Ratings
6. List of all 'TV Shows' that have 5 or more seasons.
7. List all the movies produced in 'India' that belong to the 'Comedies' category.
8. Content Added Per Year
9. Top 5 directors with the highest number of directed movies
10. 5 oldest movies released in India on Netflix.
11. Movie has the longest duration in minutes on Netflix.
12. Most recently released movie for each country.

**Learning Outcomes**
SQL querying and data exploration
Aggregation and grouping techniques
Data cleaning using SQL functions
Business insight generation from datasets
